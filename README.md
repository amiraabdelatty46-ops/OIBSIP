## 1. Bean&Co

A responsive website for a coffee shop, built with HTML5 and CSS3.

**Features**
- Clean, responsive layout that works on desktop and mobile
- Organized sections with a user-friendly design

## 2. Portfolio Website

A personal portfolio website that presents my skills and projects.

**Features**
- Responsive design across different screen sizes
- Sections for introduction, skills and projects

## 3. Temperature Converter

A simple web app that converts temperatures between **Celsius, Fahrenheit and Kelvin**.

**Features**
- Enter a temperature value and choose the unit to convert from
- Instant conversion to the other two units
- Animated thermometer that reflects the entered value
- Clean, responsive card-style interface

## How to Run

No installation is needed. For any project:

1. Clone the repository:
   ```bash
   git clone https://github.com/amiraabdelatty46-ops/OIBSIP.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
